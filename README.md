# Lord of the Halo — public feedback

This is the public bug tracker for **Lord of the Halo**, by Devon Erb / Tripple Bunk Studios. Game source and development work remain in a private Gitea repository; this repository contains feedback documentation and issue templates only.

## Report a problem

1. [Search existing issues](https://github.com/DevonErb/lord-of-the-halo-feedback/issues) and check the [pinned known-issues post](https://github.com/DevonErb/lord-of-the-halo-feedback/issues/1).
2. If your problem is not already reported, [open a bug report](https://github.com/DevonErb/lord-of-the-halo-feedback/issues/new?template=bug-report.yml).
3. Include the game version, platform, steps to reproduce, expected behavior, and what actually happened. System information is optional.

**Issues here are public.** Review anything you paste or attach, and remove personal details, access tokens, private paths, and other information you do not want published.

Website bug reports are collected privately. Reviewed summaries may be published here manually; full website reports are not automatically forwarded to this public repository. Do not paste someone else's private report here.
